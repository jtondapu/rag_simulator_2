Understand RAG Visually

This simulator demonstrates how Retrieval Augmented Generation works internally. You can observe how documents are chunked, transformed into embeddings, retrieved using semantic similarity, and finally used by an LLM to generate grounded responses.

1
Chunking
Split large text into smaller semantic pieces.
2
Embedding
Convert text into high dimensional vectors.
3
Retrieval
Search nearest vectors using semantic similarity.
4
Generation
Inject context into LLM prompt for grounded output.
